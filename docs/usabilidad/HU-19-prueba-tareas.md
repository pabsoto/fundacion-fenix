# HU-19 — Prueba de tareas con usuarios

Trazabilidad: SF-19, SF-61 y RNF-02.

Estado: pendiente de ejecución con participantes reales.

Rama de preparación: `qa-sprint1`.

La ejecuta el equipo con 3 a 5 personas reales. No se aceptan resultados inventados, simulados por el equipo ni generados automáticamente.

Participantes: 3–5, sin conocimiento previo del sitio, mezcla de móvil y escritorio.
Instrucción: "Piensa en voz alta. No te ayudaremos; si no encuentras algo, dilo."
Prerrequisito: secciones Donar/Colaborar con contenido integrado.

## Preparación

1. Abrir una versión estable del sitio sin iniciar sesión.
2. Usar como mínimo un teléfono y un equipo de escritorio entre el conjunto de participantes.
3. Asignar códigos anónimos `P1` a `P5`; no registrar nombres, correos ni datos personales.
4. Explicar que se evalúa el sitio, no a la persona.
5. Solicitar consentimiento para registrar tiempos y observaciones anónimas.
6. Ejecutar las tareas en orden alternado para reducir el efecto de aprendizaje.

Antes de convocar participantes se ejecutaron las pruebas automáticas de accesibilidad y WhatsApp: 2 archivos y 10 pruebas aprobadas el 2026-11-09. Esta comprobación técnica no sustituye la sesión humana.

## Cierre

SF-61 puede cerrarse únicamente cuando se hayan completado estos puntos:

- Participaron al menos tres personas reales sin conocimiento previo del sitio.
- Cada participante ejecutó las cinco tareas o se documentó por qué no pudo hacerlo.
- La tabla de registro contiene tiempos, resultados y observaciones anónimas.
- Se calculó la tasa de éxito y el tiempo mediano de cada tarea.
- Se registraron los problemas repetidos por dos o más participantes.
- Cada problema tiene una decisión: corregir, aceptar con justificación o crear una incidencia.
- Después de corregir un problema crítico se repitió la tarea afectada.
