# Nexora Software Consulting

Repositorio del proyecto práctico de **Ingeniería de Software (SIS-213)** 

Se presenta el trabajo de una consultora de software (**Nexora Software Consulting**) contratada por la **Fundación FÉNIX LPB** para levantar requisitos y diseñar la arquitectura de su futura página web institucional y de difusión.

---

## Información General
